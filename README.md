# Nyandwi Land Marketplace

Land and plot marketplace for Tanzania: listings, search, map (OpenStreetMap/Leaflet), platform verification, scam reporting, enquiries.

- Live: https://nyandwi-land.pages.dev/
- Backend: Supabase (Postgres + Auth + Storage, Row Level Security on every table, tables prefixed `lm_`)
- Hosting: Cloudflare Pages (static, no build step)
